Frontend - Tactical Mapping (`templates/map_view.html`):
```javascript
function createCustomMarker(soldier) {
    const statusColor = soldier.triage === 'RED' ? '#ff2a2a' :
                      soldier.triage === 'YELLOW' ? '#ffea00' : '#39ff14';
    const markerHtml = `
        <div class="custom-marker" style="
            background: ${statusColor};
            box-shadow: 0 0 10px ${statusColor};
            ${soldier.triage === 'RED' ? 'animation: pulse 2s infinite;' : ''}
        ">
            ${soldier.id.split('-')[0].charAt(0)}
        </div>
    `;
    return L.divIcon({ html: markerHtml, iconSize: [30, 30] });
}
```
