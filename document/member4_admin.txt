--- Core Logic Code Snippets ---

Systems - Startup Orchestration (`start_medicsync.bat`):
```batch
@echo off
echo [1/3] Starting Node.js Backend...
cd backend
start "Backend" cmd /k "node server.js"
timeout /t 2 /nobreak >nul
start "Simulator" cmd /k "node simulate-esp32.js"

echo [2/3] Starting Django Server...
cd ..
start "Django" cmd /k "python manage.py runserver"

echo [3/3] Launching MedicSync UI...
timeout /t 4 /nobreak >nul
start http://localhost:8000
```

Admin - Clear Report Logic (`tactical_ui/views.py`):
```python
@csrf_exempt
def api_clear_medical_view(request, soldier_id):
    if request.method == 'DELETE':
        # Purge all entries for this specific casualty
        deleted_count, _ = MedicalEntry.objects.filter(service_number=soldier_id).delete()
        return JsonResponse({
            'message': f'Cleared {deleted_count} medical entries',
            'deleted_count': deleted_count
        })
```
